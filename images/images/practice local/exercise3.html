HTML Cheatsheet

  1. <a href=""> - Creates a hyperlink
  2. <p> - Defines a paragraph
  3. <h1> to <h6> - Defines HTML headings
  4. <ul> - Creates an unordered list
  5. <ol> - Creates an ordered list
  6. <img> - Embeds an image
  7. <table> - Creates a table
  8. <form> - Defines an HTML form
  9. <div> - Defines a division or section
  10. <span> - Defines a section in a document
